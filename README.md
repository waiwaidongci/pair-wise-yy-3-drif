# 岩芯样本交付复核台

运行：

```bash
npm start
```

访问 `http://localhost:3025`。支持样本创建、切片任务、步骤记录、交付复核与快照历史。

## 复核规则

- 同一样本下切片编号不可重复，重复提交返回 409。
- 交付前校验：任一切片缺少染色方法、缺少观察结论，或 取样/切割/研磨/染色/观察 任一步骤未记录，均不得交付，接口返回 409 及缺项清单。
- 交付后新增切片、修改染色方法或补录步骤，会立即撤回交付（快照标记撤回时间与原因），并按现有切片重算样本状态。
- 重复交付不新建快照，沿用首次交付记录；携带相同 `Idempotency-Key` 的请求并发提交只执行一次。
- 每次交付生成切片快照，历史快照（含已撤回）可通过 `GET /api/samples/:id/deliveries` 或页面“交付历史”查看，刷新后样本列表、交付统计与历史保持一致。
