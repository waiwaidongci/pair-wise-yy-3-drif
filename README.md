# 岩芯样本交付复核台

运行：

```bash
npm start
```

访问 `http://localhost:3025`。

## 功能

- **切片唯一性**：同一样本下切片编号不能重复，重复时返回 409 并提示。
- **交付前复核**：缺少染色方法、观察结论，或制片五步（取样、切割、研磨、染色、观察）任一步骤未完成时，交付被驳回（422），并逐切片列出全部缺项。
- **变更即撤回**：已交付样本一旦新增切片、修改染色方法或补录步骤，立即撤回当前交付，状态按现有切片重新计算（待切割 / 制片中 / 待观察）。
- **交付快照**：每次交付留存当时各切片的方法、观察结论、已完成步骤与记录条数；旧快照可在样本「交付记录」中展开查看，撤回记录带撤回时间与原因。
- **重复交付沿用首次记录**：已交付样本再次请求交付时返回首次交付记录（`reused: true`），不产生新交付。
- **并发只成功一次**：携带相同 `Idempotency-Key` 请求头的并发交付只执行一次，所有响应共享同一结果。
- **一致视图**：样本列表与 `/api/stats`（各状态计数、有效/累计/撤回交付数）同源，刷新后历史保持一致。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/samples` | 样本列表（含切片、交付记录） |
| GET | `/api/samples/:id` | 单个样本 |
| POST | `/api/samples` | 创建样本（含初始切片） |
| POST | `/api/samples/:id/slices` | 新增切片（编号冲突返回 409；已交付时撤回交付） |
| PATCH | `/api/samples/:id/slices/:sliceId` | 修改染色方法（已交付时撤回交付） |
| POST | `/api/samples/:id/slices/:sliceId/logs` | 记录步骤（已交付时撤回交付） |
| POST | `/api/samples/:id/deliver` | 复核并交付（可带 `Idempotency-Key`） |
| GET | `/api/samples/:id/deliveries` | 交付历史（含已撤回快照） |
| GET | `/api/stats` | 状态与交付统计 |
